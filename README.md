# 💨 the.wind.rises.

## 𓇢𓆸𓇢𓆸 What is this?
the.wind.rises. turns every webpage into a windy day. Watch your words get carried away... literally.
Letters lift off and drift into the unknown, like loose thoughts, like dandelion seeds, and of course, your attention span.

## Why tho?
Because static text is boring.  
Because chaos is beautiful.  
Because maybe, just maybe, not everything needs to stay grounded.

## How it works
- On page load, letters randomly catch the breeze.
- They spin, they rise, they vanish.
- Paragraphs remain... until they don’t.

## Installation
1. Clone or download this repo.
2. In Chrome, go to `chrome://extensions/`
3. Enable "Developer mode"
4. Click "Load unpacked" and select this folder.
5. Breathe in. Let go. Refresh a page.

## Notes
- Spaces are preserved. Sanity is not.
